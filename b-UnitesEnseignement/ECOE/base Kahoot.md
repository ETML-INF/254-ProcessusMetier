# Format vrai/faux

| Kahoot # | Titre           | Question                                                                        | Réponse | Explication                                                                         |
| -------- | --------------- | ------------------------------------------------------------------------------- | ------- | ----------------------------------------------------------------------------------- |
| 1        | Forme juridique | Une entreprise individuelle sépare le patrimoine privé et professionnel.        | Faux    | L’entrepreneur est responsable sur son patrimoine privé (responsabilité illimitée). |
| 1        | Business        | Le business model décrit comment une entreprise génère ses revenus.             | Vrai    | Il explique la création de valeur et les sources de revenus.                        |
| 1        | Forme juridique | Les actionnaires d’une SA sont responsables au-delà de leur capital.            | Faux    | Leur responsabilité est limitée à leurs actions.                                    |
|          | Forme juridique | Une Sàrl nécessite plus de capital qu’une SA.                                   | Faux    | Une Sàrl demande 20'000 CHF contre 100'000 CHF pour une SA.                         |
|          | Fiscalité       | La TVA s’applique uniquement si le CA dépasse 100'000 CHF.                      | Vrai    | En dessous, l’entreprise n’est pas obligatoirement assujettie.                      |
|          | Centres         | Les centres de profit sont évalués sur leur capacité à générer des revenus.     | Vrai    | Leur objectif est la rentabilité et le chiffre d’affaires.                          |
|          | BPMN            | Les passerelles (gateways) permettent de gérer des décisions dans un processus. | Vrai    | Elles représentent les bifurcations et choix dans un flux.                          |
|          | Forme juridique | Une SNC implique au moins deux personnes.                                       | Vrai    | Elle est constituée de deux ou plusieurs associés.                                  |
|          | Centres         | Le service RH est un centre de profit.                                          | Faux    | Il est considéré comme un centre de coûts.                                          |
|          | Finance         | Le bénéfice brut inclut les coûts indirects.                                    | Faux    | Il ne prend en compte que les coûts directs.                                        |
|          | Organigramme    | Le CFO gère les ressources humaines.                                            | Faux    | Il gère les finances, pas le personnel.                                             |
|          | Organigramme    | Le CEO est responsable de la stratégie globale de l’entreprise.                 | Vrai    | Il supervise la gestion globale et les orientations stratégiques.                   |
|          | Organigramme    | Le Community Manager gère la présence sur les réseaux sociaux.                  | Vrai    | C’est son rôle principal dans le service marketing.                                 |
|          | Finance         | Le chiffre d’affaires correspond au bénéfice de l’entreprise.                   | Faux    | Le CA ne tient pas compte des coûts.                                                |
|          | Fiscalité       | L’impôt anticipé est de 8.5 %.                                                  | Faux    | Il est de 35 %.                                                                     |
